## 🌟 v0.2.0 핵심 기능 요약

### 1. 🗂️ 4대 초보자 워크스페이스 허브 (Workspace Hub)
프롬프트 작성법을 외우지 않아도 션 더블클릭 한 번으로 모든 기능을 이용할 수 있습니다.
- **✨ 바로 도움받기:** 학부모 안내문자, 업무 협조 메일, 공문 기안 초안, 회의록 요약, 엑셀 수식 등 빈출 업무 템플릿 클릭 한 번으로 완성!
- **🔍 내 파일 찾기 (폴더 지옥 탈출):** ㅇㅅㅇㄴ 초성 검색, 어제 카톡 엑셀, 한글(HWP/HWPX)·워드·엑셀·PDF 본문 단어 검색, 중복 최신본 묶음 정리 및 션에게 즉시 3줄 요약 맡기기 (100% 내 컴퓨터 안 오프라인 동작).
- **🎒 할 일 · 메모:** 오늘 할 일을 가볍게 적고 체크하면 션이 만세를 부르며 축하합니다.
- **🛠️ AI 질문 다듬기:** 전문가용 프롬프트 최적화, 빈칸 채우기, 다중 AI 비교 기능.

### 2. 🛡️ 한국형 개인정보 보호 가드 (PII Guard)
주민등록번호, 휴대전화 번호, 이메일, 계좌번호 등이 입력창에 들어오면 즉시 실시간 경고 배너를 표시하며, [🛡️ 개인정보 가리기] 버튼 클릭 한 번으로 안전하게 마스킹 변환합니다.

### 3. 💖 반려 펫의 사랑스러움 & 업무 케어 (Companion Cuteness)
- **마우스 쓰다듬기:** 션의 머리를 마우스로 문지르면 반짝이는 핑크 하트 파티클을 띄웁니다.
- **업무 시간대별 케어:** 출근, 점심, 나른한 오후, 퇴근 시간에 맞춰 정다운 말풍선을 건넵니다.
- **25분 집중 타이머:** 집중 모드를 켜면 션 머리 위에 남은 시간 배지가 표시됩니다.
- **션이 옷장:** 베레모, 해바라기 모자, 가디건, 세일러복 등 다양한 코디와 기지개·꾸벅 인사 모션.

## 🚀 빠른 시작 (설치 방법)

### 방법 A: 원클릭 간편 설치 파일 (추천)
1. [릴리스 페이지](https://github.com/Logic-k/SyeonPet/releases/latest)에서 **SyeonPet-Setup-0.2.0.exe**를 다운로드합니다.
2. 실행하면 별도의 관리자 권한(UAC) 요구 없이 %LOCALAPPDATA%\Programs\SyeonPet에 5초 만에 설치되며, 바탕화면에 **'션 데스크탑 펫'** 바로가기가 자동 생성됩니다.

### 방법 B: 무설치 포터블 압축 파일 (ZIP)
1. **SyeonPet-0.2.0-windows.zip**을 다운로드하여 원하는 폴더에 압축을 풉니다.
2. 폴더 내 **바탕화면에_션_바로가기_만들기.cmd**를 실행하면 바탕화면에 바로가기가 만들어집니다 (또는 SyeonPet.exe 직접 실행).

## 📂 패키지 구조 및 모듈 아키텍처

션 v0.2.0은 유지보수성과 확장성을 위해 깔끔하고 모듈화된 패키지 아키텍처를 갖추고 있습니다.

`	ext
SyeonPet/
├── main.py                     # 애플리케이션 진입점 및 생명주기 관리
├── pet.py                      # 펫 위젯 렌더링, 물리 드래그 및 파티클
├── behavior.py                 # 펫 행동 제어 (걷기, 대기, 고민, 수면)
├── chat.py                     # 4대 섹션 통합 워크스페이스 허브 창
├── optimizer_*.py              # 프롬프트 정리 엔진 및 AI 프로필
├── syeonpet/                   # 핵심 모듈 패키지
│   ├── chat/                   # 바로 도움받기 UI, 대화 기록, 오류 정제
│   ├── finder/                 # 스마트 파일 탐정 (초성 검색, 본문 파서, 카드 UI)
│   ├── work/                   # 서식 생성 엔진, 가방 위젯, 문서 내보내기 (TXT/MD/CSV)
│   ├── privacy/                # 개인정보 탐지 및 마스킹 가드 (정규표현식+체크섬)
│   ├── pet/                    # 모션 브리지, 퀵 액션 바, 시간대별 케어 스케줄러
│   └── ui/                     # 단축키 헬퍼, 펫 컨텍스트 메뉴
├── assets/                     # 션 스프라이트 시트, 의상 에셋, 사운드
└── docs/                       # 초보자 가이드 및 상세 개발 문서
`

## 🔒 개인정보 및 보안 정책
- **기본 정리 (오프라인):** 외부 네트워크 호출 없이 로컬 알고리즘만으로 서식과 구조를 잡습니다.
- **무료 AI (JarvisClaw · Kilo · OVHcloud):** 사용자가 전송 버튼을 누르고 사전 안내에 직접 동의한 경우에만 요청 텍스트가 전송됩니다. 서비스마다 자료 처리 방식이 달라, 프롬프트 정리와 모델 비교의 전송 확인 창에 각 운영사의 안내를 보여 줍니다(Kilo 무료 경로는 요청이 기록·학습에 쓰일 수 있음).
- **파일 검색 엔진:** 모든 파일 인덱싱과 본문 검색은 100% 로컬 PC 내부에서만 처리되며 외부로 유출되지 않습니다. 실행 파일(.exe, .bat 등)은 UI에서 실행이 원천 차단됩니다.
