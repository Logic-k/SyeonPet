# 션 데스크탑 펫 (Syeon Desktop Pet)

부산교육청 마스코트 **션**이 바탕화면을 돌아다니는 Windows 데스크탑 펫입니다.
신규 사용자 온보딩 모드(화면을 걸어 다니며 단계별 안내)를 지원합니다.

![walk](docs/walk.gif)
![celebrate](docs/celebrate.gif)

## 기능

- **배회(Wander)**: 화면 하단 작업 가능 영역 위를 왔다 갔다 걸어다닙니다.
- **온보딩 투어**: 첫 실행 시 자동 시작(설정 가능). 션이 화면 앵커 포인트를
  걸어다니며 말풍선으로 단계별 안내를 보여줍니다. `다음/◀/건너뛰기` 버튼 지원.
- **드래그 & 물리**: 션을 끌어 이동 → 놓으면 중력 낙하 + 바운스 후 착지.
- **클릭 반응**: 한 번 클릭 → 손 인사(wave), 더블 클릭 → 축하(celebrate).
- **잠(Sleep)**: 오래 가만히 있으면 졸기 시작합니다. 트레이에서 완전히 재운 동안 새 대화 전송은 일시 중지되며, 션을 클릭하거나 대화창의 `션 깨우기`를 누르면 이어갈 수 있습니다. 작성 중인 내용은 유지됩니다.
- **픽셀 단위 클릭 통과**: 창의 빈 영역은 OS 차원에서 클릭이 그대로 통과
  (`setMask` + 프레임 알파 마스크). 트레이의 "클릭 통과 모드"를 켜면
  션 본체도 통과합니다.
- **점프 & 댄스 & 누워자기**: 더블 클릭 → 축하 또는 춤(랜덤). 배회 중 가끔 점프. 오래 자면 옆으로 누워 깊이 잠듭니다(클릭 시 깨어남).
- **션 우클릭·트레이 메뉴**: 션의 몸을 우클릭하거나 알림 영역의 트레이 아이콘을 사용해 프롬프트 정리, 온보딩, 걷기·수면·춤·점프와 기타 동작을 선택할 수 있습니다. 클릭 통과 모드에서는 션의 우클릭도 통과하므로 트레이 메뉴에서 해제하세요.
- **멀티모니터**: pet이 위치한 모니터의 작업 영역을 바닥으로 인식합니다.
- **프롬프트 정리 대화**: 단일 대화창에서 요청과 추가 조건을 전달하고 결과를 직접 수정·복사할 수 있습니다. 대화창 불투명도는 60~100%로 조절할 수 있습니다. 기본 정리는 오프라인 구조화이며, AI 재작성은 외부 서비스 선택과 전송 확인 후 이용합니다. [사용·데이터 안내](docs/PROMPT_TOOLKIT_INTEGRATION.md)를 참고하세요.
- **고민 동작**: 요청을 처리하는 동안 션이 고민 자세를 보입니다. 원본 이미지 생성과 Sprite-Gen 후처리 기록은 [고민 스프라이트](docs/THINKING_SPRITE.md)에 있습니다.
- **업데이트 확인**: 시작 시 공식 GitHub 안정 릴리스를 백그라운드에서 확인하며, 메뉴에서 수동으로 확인할 수도 있습니다. 새 버전은 공식 릴리스 페이지를 안내합니다. 자동 다운로드나 파일 덮어쓰기는 하지 않습니다.
- **교육지원청 업무 예시**: 대화창의 `템플릿`에서 교육지원청 업무 예시를 필터링해 공문, 회의, 민원, 학교·시설 지원 등의 초안을 준비할 수 있습니다. [조사 근거](docs/RESEARCH_EDUCATION_MOTION.md)를 확인하고 실제 업무에는 기관 지침을 따르세요.

## Windows에서 실행

### 포함된 런타임으로 소스 실행
```bat
run.cmd
```
`SyeonPet.exe`는 같은 폴더의 `main.py`와 포함된 Python 런타임을 실행하는 런처입니다.
`run.cmd`도 같은 소스를 실행하는 대체 방법입니다. 실행 파일만 따로 복사하지 말고
런타임·소스·`assets`를 함께 유지하세요. 이 구조는 독립 단일 EXE가 아닙니다.
패키지 생성 및 기존 데이터 보존 방법은 [배포 안내](docs/RELEASE_GUIDE.md)를 참고하세요.
트레이의 `프레임 부드럽게 전환`에서 스프라이트 프레임 전환을 켜거나 끌 수 있습니다.
기존 `frame_blend_ms` 설정이 0이면 시작할 때 꺼져 있으며 변경하지 않습니다.
트레이 메뉴의 "Windows 시작 시 자동 실행"을 켜면 레지스트리
`HKCU\...\Run\SyeonPet`에 등록됩니다.

## 설정 (`config.json`)

| 키 | 설명 |
|---|---|
| `display_size` | 션 표시 크기(px). 기본 168 |
| `walk_speed` | 걷기 속도(px/s). 기본 190 |
| `start_onboarding_on_launch` | 실행 시 온보딩 자동 시작 여부 |
| `ambient_chatter` | 가끔 말풍선으로 한마디 하는지 여부 |
| `ambient_lines` | 상시 대사 목록 |
| `onboarding_steps` | 온보딩 단계 목록 — `title`, `text`, `anchor`(`left`/`center`/`right`). 이 파일만 편집하면 안내 내용을 자유롭게 바꿀 수 있습니다 |

## 스프라이트 재생성

스프라이트는 [aldegad/sprite-gen](https://github.com/aldegad/sprite-gen)
컴포넌트-로우 파이프라인으로 만들었습니다 (`assets/sprite-sheet-alpha.png`
+ `assets/manifest.json`). 상태별 스트립 원본과 프롬프트는 `qa/`·`prompts/`
가 아닌 생성 런 디렉터리에 있습니다. 재생성 절차는 `docs/SPRITES.md` 참조.

## 구조

```
syeon-pet/
  main.py         진입점: QApplication, 트레이 메뉴, 상시 대사, 자동실행 레지스트리
  pet.py          PetWidget — 프레임 렌더링, setMask 클릭 통과, 드래그+중력 물리
  behavior.py     상태 머신 — 배회/대기/수면/낙하/one-shot 액션
  chat.py         프롬프트 대화창과 불투명도·종료 확인
  optimizer_*.py  프롬프트 정리·템플릿·보관함·선택적 AI 연결
  update_checker.py 공식 GitHub 릴리스 확인, 자동 설치 없음
  onboarding.py   온보딩 투어 — 앵커 이동 + 단계별 말풍선
  bubble.py       말풍선 위젯 (펫 창의 자식 — 단일 창 설계)
  config.json     펫 사용자 설정/문구; 보관함과 불투명도는 별도 사용자 저장 공간
  assets/         sprite-gen 산출물 (시트 + manifest + 베이스)
  docs/           QA GIF, 리서치, 스프라이트 재생성 문서
```
