# 션의 추가 동작

`stretch`는 기지개, `bow`는 꾸벅 인사입니다. 각각 256×256 프레임 6개,
프레임당 250ms, 한 번 재생하는 동작입니다. 앱은 각 폴더의
`manifest.json.frame_layout`과 `sprite-sheet-alpha.png`를 읽습니다.

## 원본과 제작

- 참조는 기존 `assets/thinking/reference.png`입니다. 기존 션의 얼굴,
  초록 잎, 날개, 노란 발과 빨간 하트 가방을 유지하도록 요청했습니다.
- `source-strip.png`는 이 참조로 내장 `image_gen` 도구에서 생성한
  상태별 가로 그림입니다. 도구는 정확한 모델 버전을 반환하지 않았습니다.
- 프레임 처리에는 Sprite-Gen 3.10.1, 소스 커밋
  `c3527514630a2be2e33314421a49289a39a13a44`를 사용했습니다.
  `prepare → extract → compose-atlas → compose-gif → inspect`를 실행했습니다.
  별도 CLI 이미지 공급자나 유료 API로 전환하지 않았습니다.
- 추출은 연결된 그림 단위 분리, 공통 축척, `lanczos`, `foot-centroid`,
  바닥 정렬을 사용합니다. 칸별 고정 자르기나 포즈별 높이 확대를 하지 않았습니다.
- `curation.json`에는 모든 프레임을 12px 아래로 옮기는 위치 보정만 있습니다.
  추출 시 22px 여백으로 생기는 발 기준선을 기존 션의 y=246에 맞춥니다.
  원본 그림, 프레임 순서와 동작의 상대적인 높이는 유지합니다.
- `qa.json`은 최종 아틀라스의 프레임 수·고유 프레임 수·경계·시간,
  원본 파일 SHA-256을 기록합니다. `preview.gif`는 검토용입니다.

새 동작은 새로 생성한 포즈이므로 기존 그림과 픽셀 단위로 같지 않습니다.
포함된 의상 11종은 새 12프레임에도 자세별 시트로 맞췄습니다.
가져온 다른 외형에는 기존 동적 표시 경로를 사용합니다.
Sprite-Gen의 Apache-2.0 소프트웨어 라이선스는 션 캐릭터의 권리와 별개입니다.
