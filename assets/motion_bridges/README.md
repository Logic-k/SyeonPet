# 기존 동작 사이의 연결 그림

`sleep_bridge`는 서기에서 눕기로, `turn_bridge`는 정면에서 걷기 방향의
옆모습으로 이어지는 짧은 전환입니다. 별도의 사용자 메뉴 동작이 아닙니다.
각 행은 256×256, 6프레임이며 한 번 재생합니다.

## 제작과 보존

- 기존 션의 `idle`, `walk`, `liesleep` 프레임을 참조하여 내장 이미지
  생성 도구로 상태별 가로 행을 만들었습니다. `source-strip.png`는
  생성 결과 원본입니다. 정확한 생성 모델 버전은 반환되지 않았습니다.
- Sprite-Gen 3.10.1, 소스 커밋
  `c3527514630a2be2e33314421a49289a39a13a44`의
  `prepare → extract → compose-atlas → compose-gif → inspect`를 실행했습니다.
- 추출은 연결된 그림 단위 분리, 행 전체 공통 축척, Lanczos,
  가로 경계 중앙과 바닥 정렬입니다. 포즈마다 같은 높이로 확대하지 않아
  눕는 과정의 높이 감소가 유지됩니다. 중간 네 그림은 curation에서
  11px 아래로 옮겨 바닥을 y=245에 맞췄습니다.
- 기존 움직임과 접속할 때 그림이 바뀌는 순간을 줄이기 위해 **첫 그림은
  원래 idle의 첫 프레임으로 수동 교체**했습니다. turn의 마지막은 원래
  walk 첫 프레임 그대로이며, sleep 마지막은 원래 liesleep 첫 프레임을
  전체 256px 캔버스를 기준점 (128,245) 주위로 균일하게 0.82배
  축소했습니다(BICUBIC). 외형의 경계로 자르지 않아 모자가 잘리지 않습니다.
  이는 Sprite-Gen이 생성한 결과라고 주장하지 않는 명시적인 끝점 편집입니다.
  변경 전 추출 그림과 아틀라스는 제작 작업 폴더에 보존했습니다.
- 끝점 편집 후 실제 Sprite-Gen compose와 inspect를 다시 실행했습니다.
  `sprite-gen-manifest.json`은 그 도구의 등간격 시간 출력 그대로입니다.
  `manifest.json`에는 앱에서 요청한 프레임별 시간만 적용했습니다.

| 행 | 프레임별 시간(ms) | 전체 시간 |
|---|---|---|
| sleep_bridge | 100, 130, 170, 190, 170, 100 | 860ms |
| turn_bridge | 45, 55, 65, 65, 55, 45 | 330ms |

`preview.gif`는 위 시간으로 만든 반복 검토용 파일이며 실제 앱에서는
반복하지 않습니다. GIF 형식은 10ms 단위이므로 turn의 미리보기 시간에는
반올림 차이가 있습니다. 앱은 `manifest.json`의 정확한 시간을 사용합니다.
`contact.png`와 `qa.json`에 포즈, 경계, 원본 해시, 수동 편집을 기록했습니다.

새 그림과 기존 그림의 선·채색 차이는 남아 있습니다. 자동 형식 검사와
정적 그림 검토는 실제 앱 전환 재생 및 의상 검토를 대신하지 않습니다.
