# 옷장과 모션 확장 — 2026-10-31 개발본

## 사용 방법

- 션을 우클릭하거나 트레이 메뉴에서 **션이 옷장**을 엽니다.
- **옷 빠른 선택**에서 민트 가디건, 라벤더 목도리, 바다 세일러, 포근한 케이프를 고릅니다. 선택하면 바로 적용되고 **기본 모습**으로 돌아갈 수 있습니다.
- **움직임 미리보기**에서 기지개 또는 꾸벅 인사를 선택합니다. 재생·일시정지, 프레임 슬라이더, 좌우 반전으로 확인합니다. 미리보기의 동작은 실제 펫 상태를 바꾸지 않습니다.
- 실제 동작은 션 우클릭/트레이의 **기지개**, **꾸벅 인사**로 실행합니다. 한 번 재생한 후 대기로 돌아갑니다. 더블 클릭 동작으로도 선택할 수 있습니다.
- 대기 중에도 가끔 새 동작을 합니다. 수면·고민·끌기·안내 진행 중이나 동작 줄이기 상태에서는 새 동작이 끼어들지 않습니다. 가져온 외형에 새 동작이 없다면 해당 메뉴는 비활성화됩니다.

기존 외형 파일, 기존 의상 시트, 개인 설정과 보관함 형식은 그대로 사용합니다. 새 의상은 기존 `accessory` 설정에 선택 ID를 저장합니다.

## 이미지와 제작 과정

참조는 기존 션의 `assets/thinking/reference.png`입니다. 기지개와 꾸벅 인사는 이 참조를 내장 이미지 생성 도구에 전달해 각각 여섯 자세의 투명한 한 줄 이미지로 만들었습니다. 정확한 이미지 모델 버전은 도구가 반환하지 않았습니다.

후처리에는 [Sprite-Gen](https://github.com/aldegad/sprite-gen) 3.10.1, 소스 커밋 `c3527514630a2be2e33314421a49289a39a13a44`의 기존 가상환경을 사용합니다. 원본 생성은 내장 도구가 맡고, Sprite-Gen은 `prepare → extract → curation → compose-atlas → compose-gif → inspect`를 맡습니다. 균일한 칸으로 임의 절단하는 대신 연결된 캐릭터 영역을 추출합니다. 새 모션의 생성 원본과 제작 정보는 `assets/extra_motions/`에 둡니다.

네 의상은 기존 `source-v2`의 자세별 의상 제작 코드를 확장한 `assets/wardrobe_presets/source-v3/`에서 만듭니다. 이미지 생성 모델이 그린 의상이 아닙니다. 기본·고민 프레임을 Sprite-Gen의 `unpack-atlas`로 분해한 뒤 자체 코드로 옷과 가림 영역을 배치하고 `compose-atlas`로 조립합니다. 기존 81프레임과 새 12프레임 모두 준비된 의상 시트를 씁니다. 기존 모자를 포함한 의상 11종을 새 동작에도 맞췄으며, 모자는 나뭇잎을 숨긴 뒤 정수리에 배치합니다. 가져온 외형은 기존 방식의 동적 배치를 사용하므로 외형마다 착용감이 다를 수 있습니다.

실행 시에는 외부 이미지 서비스나 Sprite-Gen 설치가 필요하지 않습니다. 앱은 포함된 PNG와 매니페스트를 읽습니다. 새 동작은 각각 256×256 프레임 여섯 개를 한 번 재생합니다. 빠진 파일이나 잘못된 선택형 모션 파일은 건너뛰고 기존 동작을 유지합니다.

## 확인 범위

검수는 실제 프레임의 투명 여백·잘림·동작별 모습, 의상 선택과 원상 복귀, 모션 종료와 상태 잠금, 작은 옷장 창에서의 조작, 배포 ZIP에 필요한 파일이 포함되는지를 대상으로 합니다. 자동 시험과 Qt 화면 확인은 다른 PC에서의 장시간 실행을 대신하지 않습니다. 기존 AI 연결 기능의 상태는 이 변경의 검증 범위에 포함하지 않습니다.
