# 문의자와 답변 작성자 구분 시험

시험일: 2026-11-01. 서부교육지원청 업무를 가정한 **가상의 요청**을 사용해 로그인과 API 키가 필요 없는 JarvisClaw `auto/free`의 응답을 확인했습니다. 션의 실제 `optimize_ai` 경로를 사용했으며 실제 학생·학부모·직원의 정보나 비공개 자료는 보내지 않았습니다. 생성된 것은 업무 문서 자체가 아니라 다른 AI에 전달할 요청문입니다.

같은 사례를 지시문 수정 전과 중간 수정 후에 각 한 번씩 시험했습니다. 최종 지시문에는 문의자와 작성자가 원문에서 같은 사람으로 명시된 경우를 보존하는 한정 문구가 추가됐으므로, 중간 지시문의 결과를 최종 버전 전체에 대한 결과로 취급하지 않습니다. 모델의 역할 방향은 결과를 직접 읽어 확인했으며 문자 포함 여부만으로 자동 채점하지 않았습니다.

| 가상 사례 | 수정 전 | 중간 지시문 |
| --- | --- | --- |
| 학교가 교육지원청에 문의하고 담당자가 회신 | 19.95초, 방향이 대체로 일치 | 40.53초, 학교가 회신을 작성하는 것처럼 해석될 수 있음 |
| 교육지원청이 학교에 문의 | 16.30초, 방향이 대체로 일치 | 18.52초, 방향이 대체로 일치 |
| 학부모가 교육지원청에 문의하고 담당자가 회신 | 12.83초, 방향이 대체로 일치 | 8.19초, 방향이 대체로 일치 |
| 학교가 문의했으나 답변 발신자는 미정 | 11.95초, 학교가 교육지원청에 답변하는 것처럼 해석될 수 있음 | 12.02초, 학교가 교육지원청에 회신하는 것처럼 해석될 수 있음 |

최종 지시문으로 발신자가 미정인 같은 사례를 한 번 더 시험한 결과 6.50초에 응답했습니다. 답변 발신자를 `[미정]`으로 표시하면서도 학교가 교육지원청에 회신 초안을 작성하는 것처럼 표현해 결과 내부에 역할 혼동이 남았습니다. 일부 응답에는 요청에 없는 형식·분량 또는 자리표시자도 추가됐습니다.

원문에서 학교 담당자가 문의자이자 문의문 작성자라고 명시한 별도 사례는 최종 지시문으로 15.30초에 응답했습니다. 학교 담당자가 교육지원청에 문의하고 직접 문의문을 작성한다는 역할을 유지했으나 추가 형식과 자료 자리표시자도 제안했습니다. 최종 지시문은 발신자 미정과 동일 작성자 사례를 각각 한 번만 시험했습니다.

## 적용과 한계

AI 지시문은 문의자·답변 작성자·수신자를 구분하고 미지정 작성자를 임의로 정하지 않도록 보강했습니다. 원문에 문의자가 직접 작성한다고 명시한 경우에는 그 정보를 그대로 따르도록 했습니다. 문의·질의·민원과 답변·회신이 함께 들어간 요청에는 원문과 역할을 대조하라는 일반 안내를 표시합니다. 이 안내는 개인정보를 복사하지 않으며 역할을 자동으로 판정하거나 변경하지 않습니다.

사용자가 **조건 확인**에서 문의자·작성자·수신자를 선택적으로 적거나 `미정`으로 둘 수 있습니다. 답을 적용하면 원문을 바꾸지 않고 별도의 추가 조건으로 전달되며, 빈 답변과 취소는 추가 내용을 만들지 않습니다. 이 기능은 사용자가 확인한 역할을 전달할 뿐이며 AI가 이를 정확하게 따르는지 자동으로 판정하지 않습니다. 위 표와 최종 지시문 사례는 이 선택 입력을 적용하지 않고 실행했습니다.

선택 입력을 적용한 별도 가상 요청 1건도 실제 통합 경로로 시험했습니다. `문의자: 학교 / 답변자: 교육지원청 / 수신자: 학교`를 추가 조건으로 전달했을 때 JarvisClaw는 16.02초에 응답했고, 결과의 별도 역할 항목에는 세 역할이 맞게 표시됐습니다. 그러나 첫 문장은 학교가 교육지원청에 답변 문안을 작성하는 것처럼 읽힐 수 있어 역할 혼동이 남았습니다. 앱은 문의자·작성자·수신자 대조 안내를 보여 줬지만 오류를 자동 판정하거나 수정하지는 않았습니다. 한 건의 관찰로 선택 입력의 충분성이나 정확도 개선을 입증할 수 없습니다.

요청당 한 번씩 실행한 작은 표본이며, 같은 무료 별칭이 매번 다른 모델을 선택할 수 있습니다. 결과는 정확도 향상이나 지속적인 속도·안정성의 근거가 아닙니다. 문자 기반 검사는 역할 오류를 놓치거나 정상 결과에도 안내를 표시할 수 있으므로, 실제 사용 전 담당자가 문의자·작성자·수신자와 확정 여부를 원문에 대조해야 합니다. 기관의 AI 서비스 사용 승인은 별도로 확인해야 합니다.
