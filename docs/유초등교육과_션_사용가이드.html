01

션을 처음 만나요

준비된 Windows PC에서 시작합니다.

  1. 션의 GitHub 릴리스 페이지에서 Assets(첨부 파일)을 열고 SyeonPet-버전-windows.zip을 받습니다. 예를 들어 v0.1.6에서는 SyeonPet-0.1.6-windows.zip이며, 버전 숫자는 최신 릴리스에 따라 달라집니다. 이름이 .sha256으로 끝나는 파일은 검증용입니다. 기관 PC라면 내부 설치·보안 정책과 담당자 안내를 먼저 확인하세요.
  2. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 압축 풀기를 선택하고, 기존 션이 있다면 새로운 폴더에 풉니다.
  3. 압축을 푼 폴더에서 SyeonPet.exe를 두 번 눌러 실행합니다. 실행 파일만 따로 옮기지 말고 폴더 전체를 함께 보관하세요.
  4. 션의 안내가 나오면 읽고 따라가거나 건너뛸 수 있어요. 업데이트 때는 기존 창의 내용을 먼저 저장하거나 복사한 뒤 종료합니다.
처음 실행할 때 실행 파일은 디지털 서명되지 않아 Windows 경고가 나타날 수 있습니다. 경고를 임의로 우회하지 말고, 공식 배포 위치와 기관의 보안 담당자 지침을 확인하세요. 새 폴더의 설정은 기본값이며 기존 개인 설정이 자동으로 옮겨지지 않습니다.
02

첫 프롬프트를 정리해요

먼저 인터넷 없이 사용할 수 있는 기본 정리로 연습합니다.

  1. 바탕화면의 션 몸을 우클릭하고 프롬프트 정리 열기를 선택합니다. 션이 클릭되지 않으면 작업 표시줄 알림 영역의 션 아이콘 메뉴를 이용하세요.
  2. 처음에는 AI 정리 · JarvisClaw (무료)가 선택되어 있어요. 인터넷 없이 연습하려면 정리 방식 목록을 눌러 기본 정리 (AI 사용 안 함)을 직접 선택합니다.
  3. 요청 · 추가 조건 칸에 원하는 일을 적고 션에게 보내기를 누릅니다.
  4. 아래 정리 결과를 확인합니다. 가려진 부분은 창 안에서 아래로 스크롤하세요.
회의 결과를 세 항목으로 요약해 주세요.
형식: 항목별 제목과 한 문장 설명
조건: 제공하지 않은 사실은 만들지 마세요.

입력란의 연한 예시는 자동으로 입력되거나 전송되지 않으며, 첫 정리 뒤에는 추가 조건 예시로 바뀝니다. 위 문장은 연습용 가상 예시이므로 실제 인물·학교·민원 내용은 넣지 마세요.

기본 정리는 무엇을 하나요? 입력을 전달하기 쉬운 구조로 정리합니다. AI가 내용을 새로 작성하거나 정확성을 검증하는 기능은 아닙니다.
03

업무 예시를 골라 빈칸을 채워요

무엇부터 적어야 할지 막막할 때 활용하세요.

  1. 대화창에서 템플릿을 누릅니다.
  2. 교육지원청 업무 예시 보기를 누른 뒤, 예시 목록에서 필요한 항목을 선택합니다. 검색과 분야 선택도 이용할 수 있습니다.
  3. 내용 확인 및 수정에서 대괄호 [ ] 안을 가상의 내용 또는 제공이 허용된 정보로 채웁니다.
  4. 입력란에 넣기를 누르고, 대화창에서 내용과 정리 방식을 다시 확인한 뒤 션에게 보내기를 누릅니다. AI 방식이면 전송 확인창이 열립니다.
예시는 출발점이에요. 교육지원청 업무 예시는 작성 보조용이며 기관의 공식 서식이나 승인된 서비스가 아닙니다. 실제 업무에는 부서의 서식과 지침을 확인하세요.
04

결과를 살펴보고 복사해요

복사하기 전, 요청의 뜻과 조건이 그대로인지 확인합니다.

결과를 고치고 이어가기

  1. 정리 결과 칸을 클릭해 필요한 부분을 직접 고칩니다.
  2. 추가로 바꿀 조건이 있으면 위쪽 요청 · 추가 조건에 적고 다시 보냅니다.
  3. 결과 목록에서 이전 회차를 선택할 수 있어요. 대화 기록 보기로 대화 내용도 살펴볼 수 있습니다.

복사와 사용

  1. 결과 복사를 누릅니다.
  2. 사용할 문서나 허용된 도구에 붙여넣고 내용을 다시 검토합니다.
  3. 날짜·수량·기관명·출처와 담당자의 확인이 필요한 부분을 직접 확인합니다.
중요: 결과는 문서 초안 자체가 아니라 다른 도구에 전달할 요청문입니다. 외부 AI에 붙여넣는 경우에도 기관 정책과 자료 제공 가능 여부를 먼저 확인하세요.
05

다음에 쓰려면 보관해요

창을 닫아도 같은 실행 중에는 초안이 유지되지만, 앱을 종료하기 전에는 직접 저장하세요.

  1. 보관함을 열고 현재 작업 저장을 누릅니다. 원래 요청과 정리 결과가 모두 있어야 저장됩니다.
  2. 다음에 다시 보려면 목록에서 항목을 선택하고 선택 항목 불러오기를 누른 뒤 확인합니다. 현재 대화가 바뀌므로 필요한 내용은 먼저 저장하세요.
  3. 보관함 내용을 별도로 보관하려면 JSON 백업을 누르고 새 파일 이름을 선택합니다. 현재 작업을 먼저 보관함에 저장해야 백업에 포함됩니다.
  4. 복원할 때는 JSON 가져오기를 선택합니다. 기존 툴킷 보관함은 별도이므로 원본 백업을 보관한 뒤 가져온 내용을 확인하세요.

보관함과 백업에는 원문과 결과가 포함됩니다. 저장 위치와 공유 여부는 기관의 자료 관리 지침을 따르세요.

업무에 쓰기 전, 이것만 확인해요

션이 만든 문장은 사람이 마지막으로 확인합니다.

기본 정리

외부 AI 호출 없이 입력을 구조화합니다. 인터넷 연결이 없어도 이용할 수 있습니다. 앱 시작 시 업데이트 확인은 별도로 시도합니다. 사실 여부나 적합성을 자동으로 보증하지 않습니다.

기본 선택: AI 정리 · JarvisClaw (무료)

  1. 정리 방식이 AI 정리 · JarvisClaw (무료)인지 확인하고 가상의 요청을 입력합니다.
  2. 션에게 보내기를 누르면 전송 확인창이 열립니다. 보낼 내용을 검토하고 예(Yes)를 눌렀을 때만 요청합니다.
  3. 아니요(No)를 누르면 전송하지 않습니다. 외부 전송 없이 쓰려면 기본 정리 (AI 사용 안 함)을 직접 선택하세요.

원래 요청·추가 조건·이전 결과가 JarvisClaw와 외부 모델 제공자에게 전송될 수 있습니다. 전송 확인은 매번 필요하며 서비스 상태에 따라 응답하지 않을 수 있습니다.

개인정보와 비공개 자료: 학생·학부모·교직원 식별정보, 민원 원문, 비공개 문서는 외부 AI에 입력하지 마세요. 실제 업무에 사용하기 전 기관이 허용한 서비스와 자료 처리 기준을 확인하세요.

션을 꾸미고, 새 버전을 준비해요

익숙한 션의 기능은 그대로 이용할 수 있어요.

션이 옷장

  1. 션을 우클릭하거나 알림 영역의 션 아이콘을 눌러 션이 옷장을 엽니다.
  2. 옷 빠른 선택에서 모자, 목도리, 가디건, 앞치마를 고르면 바로 적용됩니다. 옷 선택에 인터넷이나 AI는 필요하지 않아요.
  3. 움직임 미리보기에서 걷기나 잠자기 등을 고르고 재생을 누르면 움직이는 모습을 볼 수 있어요. 일시정지한 뒤 막대를 움직여 한 장씩 보거나 좌우 반전을 선택할 수도 있어요.
  4. 장식을 없애려면 기본 모습을 고르세요. 가져온 외형도 되돌리려면 외형 팩에서 기본 외형을 함께 선택합니다. 직접 만든 호환 팩은 가져오기로 선택할 수 있어요.

일부 자세나 가져온 외형에서는 옷이 다르게 보이거나 가려질 수 있어요.

새 버전 적용하기

  1. v0.1.5 이하에서 처음 옮길 때는 새 ZIP을 한 번 직접 받아 다른 폴더에 압축을 풉니다. 필요한 대화와 보관함을 먼저 저장하고 JSON 백업을 보관하세요. 개인 설정은 새 폴더로 자동 이전되지 않습니다.
  2. 그다음부터는 서명과 파일 검증을 통과한 새 버전을 자동으로 준비합니다. 준비 알림이 보이면 션 메뉴에서 종료하고 다시 실행하세요.
  3. 준비된 업데이트가 있을 때 정상 종료하면 작성 중인 대화 복원을 시도합니다. AI 요청이나 확인창이 열려 있다면 먼저 작업을 마치고 종료하세요.

강제 종료나 Windows 종료에서는 초안 보존을 보장하지 않습니다. 중요한 내용은 보관함에 저장하고 JSON으로 따로 백업하세요. 업데이트 실패 시 기존 버전을 계속 사용할 수 있도록 복구를 시도합니다.

이럴 땐 이렇게 해요

급하게 닫지 않아도 괜찮아요.

션이 자고 있어요션을 클릭하거나 대화창의 션 깨우기를 누릅니다. 완전히 자는 동안에는 새 요청을 보내지 못합니다.
