# AI 연결과 프롬프트 검토

## 연결을 선택하기

로그인이나 키 없이 사용하려면 프롬프트 창의 **정리 방식**에서 서비스 항목을 선택합니다. 외부 서비스에 보내기 전에는 전송 내용을 확인하는 창이 나타납니다. **기본 정리 (AI 사용 안 함)**는 외부 AI를 호출하지 않고 입력을 구조화합니다.

- **JarvisClaw**: 처음 선택되는 **AI 정리 · JarvisClaw (무료)**입니다. 앱을 열거나 선택하는 것만으로 전송되지 않으며, 매 요청마다 내용과 대상을 확인한 뒤 사용자가 전송을 선택해야 합니다. 공식 안내의 `auto/free` 모델은 로그인과 API 키 없이 쓸 수 있으며 IP별 사용 제한이 있습니다. 여러 모델 중 하나가 응답하므로 속도와 품질이 달라질 수 있습니다. 외부 모델 공급자의 처리 조건과 기관 지침을 확인하세요.
- **Vireonix / Pollinations Classic**: 키 없이 선택할 수 있는 기존 서비스입니다. Pollinations의 공식 개인정보처리방침에는 계정 없는 Free API Classic이 명시되어 있습니다. 서비스 장애, 응답 지연과 이용 조건 변경이 생길 수 있습니다. 아래 시험 결과는 지속적인 사용 가능성이나 기관의 승인 여부를 보장하지 않습니다.

**Murakumo**는 키 없는 대안으로 조사했지만 앱 요청에서 반복적으로 오류가 발생해 현재 선택지에 추가하지 않았습니다. [서비스 안내](https://murakumo.cloud/free)는 제3자 노드 운영자가 무료 요청의 입력과 응답을 볼 수 있다고 설명합니다. [이용 약관](https://murakumo.cloud/legal-terms)은 현재 초안이라고 표시하며 조직을 대신한 이용에는 권한이 필요하다고 명시합니다.

AI가 만든 문장은 날짜·수량과 대상을 바꾸거나 내용을 덧붙일 수 있으므로 원문과 비교해 확인하세요. 가상 연수·회의록 요청 두 건은 실제 앱 경로에서 각각 11.7초와 22.5초에 완료됐지만, 회의록 요청에서 금지 조건의 의미가 바뀐 사례가 있었습니다. 소수의 시험이 정확성이나 안정성을 보장하지 않습니다. [무료 AI 실제 시험 기록](CLOUD_AI_TEST_2026-10-31.md)을 참고하세요.

사무실 PC의 성능이 낮다면 모델 설치가 필요한 로컬 방식보다 외부 AI 연결을 먼저 살펴보세요. 외부 서비스는 인터넷 연결과 공급자별 한도·자료 처리 조건이 적용됩니다. **기본 정리**는 모델 설치가 필요 없는 문장 구조화 기능이며 AI 재작성은 아닙니다. 실제 업무자료 전송 전에는 기관의 지침과 사용 승인 여부를 확인하세요.

다음은 별도의 로그인이나 키가 있는 경우에만 **AI 설정**에서 선택할 수 있는 기존 연결입니다. 설정을 추가하거나 바꾸는 것만으로 정리 요청을 보내지는 않습니다.

- **ChatGPT 구독**: 공식 로그인 창에서 션의 연결과 구독 한도 공유를 확인합니다. 로그인한 계정에서 제공하는 모델만 선택합니다. 이 연결은 별도 API 키 결제와 다르며, 구독·계정·워크스페이스의 한도가 적용됩니다. 구독 한도를 소진해도 유료 API나 다른 서비스로 자동 전환하지 않습니다. 현재 PC에서는 계정이 연결되지 않아 이번 실제 생성 시험을 하지 않았습니다.
- **Groq / Gemini**: 자신의 API 키를 연결하고 해당 계정·프로젝트가 무료 구간인지 직접 확인합니다. 션에서 무료 구간 확인을 선택해도 공급자의 결제 설정을 바꾸거나 무료를 보장하지 않습니다.
- **OpenRouter**: 무료 모델은 `:free`로 끝나는 모델 ID를 선택합니다. 무료 모델도 일일 한도·가용성 제한과 실제 추론 공급자의 데이터 정책을 따릅니다.
- **Ollama**: 별도로 설치하고 모델을 준비한 로컬 서버를 사용합니다. 션은 모델을 자동으로 설치하거나 내려받지 않습니다. 서버에서 `OLLAMA_NO_CLOUD=1` 또는 `disable_ollama_cloud=true`를 설정하고 재시작한 뒤 확인을 선택합니다. 로컬 주소라는 이유만으로 클라우드 기능이 꺼지는 것은 아닙니다.

무료 웹 채팅, 무료 API, 기존 ChatGPT 구독, 로컬 모델은 같은 상품이 아닙니다. 선택할 수 있는 모델과 한도는 공급자·계정에 따라 달라집니다.

## 전송 전에 확인하기

정리 요청은 기존처럼 전송 대상과 내용을 확인한 뒤 진행합니다. 원래 요청, 추가 조건과 선택한 이전 결과가 포함될 수 있습니다. 연결·모델·입력·키 또는 계정 상태가 확인 중 바뀌면 다시 확인합니다.

ChatGPT 구독 연결은 텍스트 응답만 요청합니다. 셸·파일·MCP 도구를 실행하는 에이전트가 아니며 Codex의 저장된 로그인 토큰을 가져오지 않습니다.

외부 API에는 사용자가 선택한 공급자의 데이터 처리 조건이 적용됩니다. 학생·학부모·직원 식별정보나 비공개 자료는 기관에서 허용한 경로와 자료인지 확인하세요. 오류나 한도 초과 때 기존 입력과 결과는 남으며 자동으로 다른 공급자에게 보내지 않습니다.

## 부족한 조건 채우기

정리 전에 조건 확인 도우미를 열어 목적·대상·형식·기한 중 필요한 내용을 보완할 수 있습니다. 규칙으로 찾은 참고 질문이며 모든 요청에 이 네 항목이 필수인 것은 아닙니다. 답하지 않고 계속하거나 취소해도 원문을 임의로 채우지 않습니다.

문의에 대한 답변이나 회신을 준비할 때는 **도구 더보기 → 조건 확인 → 문의·답변 역할**에서 문의자·답변 작성자·수신자를 직접 적거나 `미정`으로 둘 수 있습니다. 입력은 선택 사항이고, 적용하면 원문을 바꾸지 않고 추가 조건으로 전달합니다. 실제 가상 시험에서 역할을 지정해도 첫 문장에서 문의자와 답변자가 혼동된 사례가 있어, 결과 전체를 원문과 대조해야 합니다. 이 기능과 검토 안내는 역할을 자동 판정하거나 교정하지 않습니다.

답변을 적용하면 원래 요청을 바꾸는 대신 추가 조건으로 사용합니다. 긴 자료를 넣어 입력 한도를 넘으면 내용을 줄인 뒤 다시 시도하세요.

## 원문과 결과 비교

현재 편집한 결과와 원문의 달라진 부분, 숫자·날짜·요일·시간·인용 문구·금지조건의 문자상 보존 여부를 확인합니다. 이는 **문자 비교**이며 의미나 사실관계의 검증 완료 표시가 아닙니다. 결과를 편집한 뒤 다시 확인할 수 있습니다.

원문에 문의·희망·예정·미확인 표현이 있는데 결과에 `확인된 사실`이나 `확정` 표현이 감지되면 원래의 상태를 대조하라는 참고 경고가 나타날 수 있습니다. 단어를 비교하는 보조 기능이므로 실제로 바뀌지 않은 내용에도 경고할 수 있고, 주체나 일정의 의미 변화가 모두 탐지되는 것도 아닙니다.

같은 실행에서 만든 결과는 요청 당시의 원문과 조건 확인 도우미의 추가 조건을 기준으로 검토합니다. 비교 결과를 다시 선택할 때도 각 결과의 조건 경고를 볼 수 있습니다. 보관함이나 이전 실행에서 복원한 결과에는 당시 조건 이력이 없을 수 있으므로 사용자가 직접 원문을 대조하세요.

명시적으로 제공한 자료를 인식했고 AI가 자료 관련 ‘붙여 넣기’ 빈칸을 하나만 남긴 경우, 앱이 자료 원문을 그 칸에 넣을 수 있습니다. 여러 빈칸이나 수정 요청에는 자동으로 넣지 않습니다. 모든 자료 형식을 인식하지는 못하므로 자료가 제대로 들어갔는지 확인하세요.

## 두 결과 비교

비교할 연결·모델 두 개와 전송 내용을 확인한 뒤 사용자가 비교를 시작합니다. 두 결과를 얻는 작업이므로 최대 두 번 요청합니다. 첫 결과를 두 번째 모델에 자동 전달하지 않습니다.

첫 번째 결과가 성공하고 두 번째가 실패해도 성공한 결과는 남습니다. 모델별 결과를 직접 읽고 선택하며, 앱이 임의로 승자를 정하지 않습니다. 표시한 응답 시간은 해당 요청의 측정값이지 모델 전체의 성능 평가가 아닙니다.

## 개인 연결과 백업

연결 이름·모델 등 비밀이 아닌 프로필과 API 키·로그인 토큰은 별도 저장합니다. 비밀값은 현재 Windows 사용자용 보호 저장소에 보관하며 보관함 JSON, 대화 복원 파일과 배포 ZIP에 포함하지 않습니다. 다른 PC로 ZIP을 옮겨도 개인 연결 자격정보는 자동으로 이전되지 않습니다.

API 키 제거 또는 로그아웃은 해당 연결에서 새 요청을 보낼 수 없게 합니다. 외부 서비스의 이미 처리한 요청이나 기록을 지우는 기능은 아닙니다.

## 오픈소스 참고와 라이선스

Ollama의 로컬 모델 검색·검사·대화 분리, Open WebUI의 연결/모델 설정 분리, LiteLLM의 공급자별 응답 정규화 구조를 조사했습니다. 서버 프레임워크나 해당 UI 코드를 션에 복사·동봉하지 않고 필요한 작은 REST 경계를 구현합니다. 모델을 별도 설치할 때는 해당 모델의 라이선스도 확인하세요.

- Ollama: https://github.com/ollama/ollama (MIT), https://docs.ollama.com
- Open WebUI: https://github.com/open-webui/open-webui (현재 별도 라이선스)
- LiteLLM: https://github.com/BerriAI/litellm (범위별 라이선스 확인)
- 공식 ChatGPT 앱 연결: https://developers.openai.com/siwc/token-sharing-open-source

로그인·무료 한도·데이터 처리 조건은 바뀔 수 있습니다. 이 문서는 특정 계정의 가입 승인이나 영구 무료 사용을 보장하지 않습니다.
