# 션과 프롬프트 정리 대화

## 실행과 사용

Windows에서 `SyeonPet.exe` 또는 `run.cmd`를 실행합니다. `SyeonPet.exe`는 함께 있는 `main.py`와 Python 런타임을 사용하는 런처이므로 파일 하나만 복사하면 안 됩니다. 이미 구버전 션이 실행 중이라면 필요한 대화 내용을 먼저 저장하거나 복사하고 구버전을 종료한 뒤 새 폴더에서 실행하세요.

1. 션의 몸을 우클릭하거나 알림 영역의 션 트레이 메뉴에서 **프롬프트 정리 열기**를 선택합니다. 대화창은 프롬프트 정리 전용입니다.
2. 기본 선택은 **AI 정리 · Vireonix**입니다. 외부 전송 없이 연습하려면 정리 방식을 **기본 정리 (AI 사용 안 함)**으로 바꿉니다. 원하는 일을 입력하고 **션에게 보내기**를 누릅니다. AI 방식은 전송 확인창에서 사용자가 동의한 경우에만 요청을 보냅니다. 추가 조건이 있으면 같은 대화에서 이어서 입력합니다.
3. 정리 결과를 직접 읽고 수정한 뒤 복사합니다. 이전 회차의 결과도 선택해 확인할 수 있습니다.
4. **템플릿**에서 **교육지원청 업무 예시 보기**를 선택해 업무 예시를 검색·편집한 뒤 입력란에 넣을 수 있습니다. 기존 일반 예시도 사용할 수 있습니다. **새 요청**을 누르면 기존 대화를 지우기 전에 확인합니다.

기록을 확인하려면 **대화 기록 보기**를 누릅니다. 기록을 접더라도 원문·결과·추가 조건은 지워지지 않습니다. **정리 결과**는 편집할 수 있으며, 안내가 길면 상태 영역을 스크롤해 나머지를 확인하세요.

처음에는 요청 입력란에 가상의 연수 안내문 예시가 연하게 표시됩니다. 작성하기 시작하면 예시는 사라지며 실제 입력이나 전송 내용에 자동으로 포함되지 않습니다. 첫 정리 후에는 추가 조건을 쓰는 예시가 표시됩니다.

첫 정리 전에 결과 칸에 직접 쓴 내용이 있으면 첫 결과를 만들 때 **직접 작성한 결과**로 보존됩니다. 결과 선택 목록에서 확인할 수 있으며 첫 AI 요청에 자동으로 포함되지 않습니다. 좁은 창에서는 정리가 끝난 뒤 결과가 보이도록 화면을 이동할 수 있습니다. 추가 조건을 쓰려면 요청 입력란을 다시 선택하세요.

션 우클릭 또는 트레이에서 **완전히 가만히 재우기**를 선택하면 새 대화 전송이 중지됩니다. 기존 입력과 결과를 지우지 않으며, 션을 클릭하거나 대화창에서 **션 깨우기**를 누르면 다시 전송할 수 있습니다. 이미 진행 중인 요청은 강제 취소하지 않습니다. **프레임 부드럽게 전환**은 선택 기능이며 이전 설정이 0이면 시작할 때 꺼져 있습니다. 클릭 통과 모드에서는 션의 몸도 클릭을 받지 않으므로 트레이 메뉴에서 해제합니다.

요청을 처리하는 동안 션이 고민 동작을 재생합니다. 대화창 위쪽의 **창 불투명도** 조절은 60~100%로 적용되며 100%에서 가장 선명합니다. 반투명한 창은 뒤의 화면에 따라 읽기 어려워질 수 있습니다. 창을 닫았다 다시 열어도 작성 중인 입력은 같은 실행 동안 유지됩니다. 앱 종료 전 미저장 작업이나 진행 중인 요청이 있다면 종료 여부를 다시 확인합니다.

### 션이 옷장

션을 우클릭하거나 트레이 메뉴에서 **션이 옷장**을 선택합니다. **하늘 리본**, **반짝 별**, **학사모**를 고르면 펫에 바로 표시되며 **기본 모습**으로 되돌릴 수 있습니다. 외형 팩의 **가져오기**는 이미 완성된 로컬 스프라이트 폴더를 선택하는 기능입니다. 폴더에는 `manifest.json`, `sprite-sheet-alpha.png`, `thinking/manifest.json`, `thinking/sprite-sheet-alpha.png`가 필요하고, 모든 필수 동작 프레임과 투명도·크기·재생 정보를 검사합니다. 원본은 변경하지 않고 사용자별 공간에 별도 복사합니다.

형식이 올바르더라도 의상이나 캐릭터의 위치가 모든 동작에 자연스럽게 맞는지는 사용자가 살펴봐야 합니다. 옷장은 AI 이미지를 생성하거나 외부 서비스에 보내지 않습니다. Sprite-Gen은 별도 도구이며 이미지 생성 서비스와 실제 생성·검수 과정은 이 가져오기 기능에 포함되지 않습니다. 원본과 새 외형의 사용·재배포 권리도 별도로 확인하세요.

### 가독성 설계 참고 자료

입력란의 지속적인 제목, 텍스트와 배경의 대비, 좁은 창과 확대 설정을 고려할 때 [Microsoft의 접근 가능한 텍스트 안내](https://learn.microsoft.com/en-us/windows/apps/design/accessibility/accessible-text-requirements)와 [Windows 앱 접근성 모범 사례](https://learn.microsoft.com/en-us/windows/apps/get-started/best-practices), [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)를 참고했습니다. WCAG는 웹 표준을 데스크톱 설계에 참고한 것이며 접근성 인증을 의미하지 않습니다. 시스템 고대비 테마와 모든 배율·반투명 배경에서의 대비는 별도 검증이 필요합니다.

처음 선택된 **AI 정리 · Vireonix**를 포함해 외부 AI 방식은 매 요청 전에 전송을 확인하며, 시작하거나 대화창을 여는 것만으로 요청을 보내지 않습니다. 확인하면 원래 요청, 추가 조건과 이전 결과가 해당 외부 서비스에 전달됩니다. 직접 선택할 수 있는 **기본 정리 (AI 사용 안 함)**는 원문과 조건을 그대로 구조화하는 오프라인 기능이며 AI 재작성이나 품질 평가가 아닙니다. 제공자의 서비스 정책과 이용 가능 범위는 변경될 수 있으므로 민감한 내용을 입력하기 전에 확인하세요. 정리 결과의 의미와 조건은 직접 검토해야 합니다.

## 보관함과 데이터

**보관함**에서 사용자가 명시적으로 저장한 작업만 션의 별도 로컬 보관함에 저장합니다. 기존 툴킷의 WebView2 보관함에는 접근하지 않습니다. 기존 툴킷에서 JSON 백업을 내보낸 뒤 션 보관함의 **JSON 가져오기**를 사용하면 항목을 추가할 수 있습니다. 기존 항목은 자동으로 이전되지 않습니다. 가져오기 전에 백업을 별도 보관하세요.

션의 JSON 백업은 기존 툴킷의 버전 1 구조를 사용하고, 이어진 추가 조건은 션 전용 `syeonRevisions` 필드에 보관합니다. 기존 툴킷에서 션의 백업을 가져왔다가 다시 내보내면 툴킷이 이 추가 필드를 제거할 수 있으므로, 션에서 내보낸 원본 백업을 보존하세요. 보관함과 백업에 원문과 결과가 들어갑니다.

교육지원청 업무 예시는 부산 서부교육지원청 공개자료를 참고해 만든 작성 도우미이며 공식 서식이나 기관 승인 AI를 뜻하지 않습니다. 개인정보·비공개 자료와 민원 원문은 기관 지침을 확인하고 가상의 예시나 제공이 허용된 자료를 사용하세요. 출처와 설계 근거는 [개발 조사](RESEARCH_EDUCATION_MOTION.md)에 있습니다.

## 구조와 배포

션은 기존 Python/PySide6 이벤트 루프와 펫 동작을 유지하며, 대화창은 프롬프트 정리에 집중합니다. 프롬프트 툴킷의 오프라인 구조화·문자 기반 검토·49개 템플릿과 두 서비스의 AI 요청 방식을 Python 대화창에 이식했습니다. 툴킷의 전체 Tauri 화면이나 WebView2 보관함을 내부에 끼워 넣은 것은 아닙니다. 사용자는 기존 툴킷도 그대로 사용할 수 있습니다.

소스 출발점은 SyeonPet `10f70cd59b63765c854c764b85a8e22e7cc635c4`, prompt-toolkit-desktop `b44baedd028988e26fd227113fe8c4855c1e0541`입니다. 포함된 `SyeonPet.exe` 또는 `run.cmd`, Python 런타임, 라이브러리, `assets`, 소스를 함께 사용합니다. `SyeonPet.exe`의 폴더 내 소스 실행은 격리된 합성 코드로 확인했으며, 이는 독립 단일 EXE 빌드나 다른 PC 배포를 확인했다는 뜻은 아닙니다. [배포 안내](RELEASE_GUIDE.md)를 참고하세요.

## 업데이트

자동 업데이트를 지원하는 버전에서는 공식 GitHub의 최신 안정 릴리스를 확인한 뒤 서명과 파일을 검증한 업데이트를 별도 사용자 저장 공간에 준비합니다. 메뉴의 **업데이트 확인**으로 직접 확인할 수도 있습니다. 준비가 끝나면 트레이에서 종료하고 다시 실행할 때 적용을 시도합니다. 업데이트 과정에서 저장한 대화 초안의 복원을 시도하며 설정과 보관함은 기존 위치를 사용합니다. 인터넷이 없거나 검증에 실패하면 기존 버전을 계속 사용할 수 있습니다. 복원용 초안도 민감한 원문을 포함할 수 있으므로 사용자 저장 공간을 보호하고 보관함의 JSON 백업을 별도로 유지하세요. v0.1.5 이하는 자동 업데이트를 지원하지 않아 처음 한 번 새 버전을 직접 설치해야 합니다. ## 확인 범위

이전 구현의 2026-10-30 검증에서는 자동 시험 99건과 업무 템플릿 선택·기본 정리·결과 편집, Vireonix 합성 요청의 응답 표시를 확인했습니다. 별도 시험 창에서는 실제 마우스로 수면 중 캐릭터의 투명 영역 클릭 통과와 몸 클릭으로 깨우기를 확인했습니다. 이후 단일 대화창과 새 메뉴가 추가되었으므로 최신 변경의 시험 결과로 간주하지 마세요. 전환 중 클릭 통과, 전체 창 클릭 통과 옵션과 멀티모니터는 확인하지 않았습니다.

2026-10-30 합성 요청에서 Vireonix와 Pollinations Classic이 각각 한 차례 성공했지만 일부 요청은 시간 초과 또는 HTTP 502를 반환했습니다. Vireonix 429·502·503·504는 같은 제한 시간 안에서 1초, 2초 간격으로 최대 두 번 다시 시도하지만 외부 서비스의 가용성을 보장하지는 않습니다. AI가 원문 수량 조건을 바꾼 사례에 대해 일부 패턴을 경고하도록 했으나, 모든 의미 변형을 찾지는 못합니다. 새 PC, 실제 멀티모니터 및 Windows 시작 자동 실행, 실제 사용자 보관함 이전은 별도 확인이 필요합니다.

2026-10-30 추가 확인에서 Vireonix가 비슷한 이전 요청의 답을 다시 돌려주는 현상을 재현했습니다. 요일이나 학교 수를 바꾼 요청에도 이전 값이 든 답이 돌아왔습니다. 이제 요청마다 임의의 구분 번호를 함께 보내며, 같은 시험에서 바뀐 값이 반영되는 것을 확인했습니다. 내용이 완전히 같은 요청은 이전과 같은 답을 받을 수 있습니다. AI 지시문은 목적, 지킬 조건, 결과 형식과 말투, 빠진 정보를 위한 [대괄호] 칸, 자료 칸을 갖춘 프롬프트를 만들도록 바꾸었습니다. 첫 정리 결과에서 원문의 숫자나 따옴표 문구가 빠지거나 정확한 수량 범위가 바뀌면 원래 요청을, 붙여 넣은 자료만 빠지면 그 자료를 결과 끝에 원문 그대로 붙입니다. 이 검사는 문자 단위이므로 의미 변화까지 찾지는 못합니다. 합성 요청 소수로 확인한 결과이며 자동 선택 모델에 따라 품질과 응답 시간이 달라질 수 있습니다.
