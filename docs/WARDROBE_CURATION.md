# 션이 옷장: 움직임과 의상 검토

션의 기존 움직임은 기본 아틀라스 75프레임과 별도 고민 동작 6프레임으로 구성됩니다. 옷장이 원본 이미지를 덮어쓰지 않고 이 프레임을 표시하도록 유지하며, 의상을 선택한 뒤 **움직임 미리보기**에서 동작과 프레임을 확인할 수 있습니다. 옷 선택과 미리보기에는 이미지 생성 서비스, 별도 계정이나 인터넷이 필요하지 않습니다.

## 왜 자세별 검토가 필요한가요?

정면 옷 이미지를 모든 자세에 같은 방향으로 붙이면 옆모습이나 누운 모습에 맞지 않고, 얼굴·날개·가방의 앞뒤 관계가 어긋날 수 있습니다. 프레임 개수와 파일 형식이 올바르더라도 착용 모습이 자연스럽다는 뜻은 아닙니다. 서기, 걷기, 끌려가기, 앉아 자기, 누워 자기, 엎드려 자기, 고민과 좌우 반전을 살펴보고, 움직임 전환 시 위치가 튀거나 잘리는지도 확인합니다.

현재 누워 있거나 엎드린 자세에서는 목도리가 머리 아래에 가려지고 가디건과 앞치마는 등 일부만 보입니다. 걷기 측면의 모자는 별도 측면 그림이 아니라 같은 모자를 자세에 맞춰 변형한 것입니다.

기본 션과 픽셀이 다른 사용자가 가져온 외형에는 기존의 동적 의상 표시 방식을 유지합니다. 가져온 외형은 자세와 색이 다를 수 있어 기본 션과 똑같이 맞는다고 보장할 수 없습니다. 기존 외형 파일과 사용자 설정을 덮어쓰지 않으며, **기본 모습**과 **기본 외형**으로 각각 되돌릴 수 있습니다.

## 오픈소스 도구의 역할

[Sprite-Gen](https://github.com/aldegad/sprite-gen)은 Apache-2.0 라이선스의 스프라이트 제작 도구입니다. 기존 아틀라스를 상태별 프레임으로 나누는 `unpack-atlas`, 프레임을 확인하고 위치 등을 정리하는 [curation](https://github.com/aldegad/sprite-gen/blob/main/docs/curation.md), 다시 시트로 만드는 `compose-atlas` 같은 도구가 있습니다. 이는 개발자의 오프라인 작업을 돕는 기능이며, 옷의 착용 위치와 앞뒤 가림을 자동으로 맞춰 주지는 않습니다. Sprite-Gen 소프트웨어의 라이선스는 션 캐릭터의 사용·재배포 권리와 별개입니다.

이번 의상 재작업에서는 Sprite-Gen 3.10.1(소스 커밋 `c3527514630a2be2e33314421a49289a39a13a44`)을 별도 가상환경에 설치하고, 기본 아틀라스와 고민 동작을 각각 아래 명령으로 실제 분해했습니다. 의상을 자세에 맞추는 작업은 별도로 수행하며, 아래 명령이 착용 위치나 가림을 자동으로 완성해 주지는 않습니다.

```powershell
python -m sprite_gen.cli unpack-atlas --atlas assets/sprite-sheet-alpha.png --manifest assets/manifest.json --out-dir <기본_작업_폴더>
python -m sprite_gen.cli unpack-atlas --atlas assets/thinking/sprite-sheet-alpha.png --manifest assets/thinking/manifest.json --out-dir <고민_작업_폴더>
```

분해한 프레임에 의상과 가림 영역을 배치하는 작업에는 자체 오프라인 코드와 프레임별 실측을 사용했습니다. 이후 Sprite-Gen의 `compose-atlas --run-dir <작업_폴더>`를 일곱 의상에 대해 기본 동작과 고민 동작 각각 한 번씩, 총 14회 실행해 의상 시트를 만들었습니다. 이 작업은 이미지 생성 모델을 호출하지 않았습니다. 앱은 의상 시트의 재생 정보 대신 기존 `SpriteBank`의 원본 매니페스트를 사용해 각 동작의 시간을 유지합니다.

기존 75개와 고민 6개 프레임을 Sprite-Gen 3.10.1(소스 커밋 `c3527514630a2be2e33314421a49289a39a13a44`)의 독립된 Windows Python 환경에서 `unpack-atlas`와 `compose-atlas`로 왕복한 이전 호환 시험에서는, 보이는 픽셀과 알파는 유지됐지만 일부 프레임의 재생 시간이 달라졌습니다. 이 실험은 옷의 착용 품질에 대한 검증이 아닙니다. 원본 동작을 재조립할 경우 원본 `durations_ms`와 반복 여부를 별도로 확인해야 합니다.

개발 시 프레임·레이어 편집과 연속 동작 확인에는 [LibreSprite](https://github.com/LibreSprite/LibreSprite)나 [Krita 애니메이션 기능](https://docs.krita.org/en/user_manual/animation.html)도 참고할 수 있습니다. 이 도구들 역시 자세별 옷을 자동으로 정확하게 맞춰 주지는 않으며, 사용자 앱에 이 프로그램을 설치할 필요는 없습니다.
