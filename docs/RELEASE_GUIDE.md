# Windows 패키지와 업데이트 안내

## 실행

이 프로젝트는 Python과 PySide6로 동작합니다. `SyeonPet.exe`는 같은 폴더의 `main.py`와 포함된 Python 런타임을 실행하는 런처이며, `run.cmd`는 대체 실행 방법입니다. 둘 중 하나만 옮기는 독립 실행 파일은 아닙니다. 소스와 `assets`, Python·Qt 런타임 및 설정 파일을 함께 유지해야 합니다.

기존 런처가 같은 폴더의 합성 `main.py`를 실행하는 동작은 별도 임시 폴더에서 확인했습니다. 이 시험만으로 새로 생성한 ZIP의 완전성이나 다른 PC의 실행까지 보장할 수는 없습니다.

기존 런처는 코드 서명되지 않았습니다. Windows가 실행 전 신뢰 여부를 물을 수 있으며, 다운로드한 파일은 공식 릴리스 위치와 공개된 SHA-256을 확인하세요.

## 새 버전 설치와 기존 데이터

1. 기존 션에서 필요한 대화 내용을 보관함에 저장하거나 복사하고 앱을 종료합니다.
2. 새 ZIP을 **기존 앱과 다른 폴더**에 풉니다. ZIP에는 배포용 기본 `config.json`이 들어 있으므로 기존 폴더에 그대로 덮어쓰면 개인 설정을 잃을 수 있습니다.
3. 새 폴더에서 `SyeonPet.exe` 또는 `run.cmd`를 실행합니다. 기존 설정을 쓰려면 먼저 기존 `config.json`을 별도로 백업한 후 내용을 확인하고 직접 옮깁니다. 설정이나 보관함을 삭제하는 과정은 없습니다.
4. 션 보관함은 사용자별 로컬 저장 공간에 별도로 존재합니다. 이전 전에 프로그램에서 JSON 백업을 보관하고 새 환경에서 결과를 확인하세요. 브라우저 기반 기존 프롬프트 툴킷의 보관함은 별도이며 JSON 가져오기로 사용자가 선택해 옮길 수 있습니다.

실제 개인정보·비공개 문서는 외부 AI에 전송하기 전 기관의 정책과 허용된 서비스를 확인해야 합니다. 기본 정리는 외부 전송 없는 구조화 기능이며 AI 재작성은 아닙니다.

## 업데이트 확인의 범위

시작 시 공식 GitHub의 최신 안정 릴리스를 백그라운드에서 확인하며, 션 우클릭 또는 트레이 메뉴의 **업데이트 확인**으로도 조회할 수 있습니다. 릴리스가 없거나 인터넷이 없어도 펫을 계속 사용할 수 있습니다. 새 버전이 있으면 공식 릴리스 페이지를 열지 사용자가 선택합니다.

자동 다운로드·실행·설치·기존 파일 교체는 구현되어 있지 않습니다. 릴리스 페이지와 체크섬을 확인한 뒤 위의 새 폴더 방식으로 사용하세요. 체크섬은 다운로드 파일이 제시된 값과 같은지 확인하는 데 쓰이며, 단독으로 작성자의 신원을 증명하지는 않습니다.

## 패키지 생성

Windows에서 저장소 루트를 기준으로 Python 3.10 이상을 사용합니다. 다음 명령은 `version.py`의 버전과 일치해야 하며 ZIP은 저장소 밖의 **아직 존재하지 않는** 경로에 생성합니다.

```powershell
python tools/build_release.py --version 0.1.0 --output <새_출력_폴더>/SyeonPet-0.1.0-windows.zip
```

필요하면 `--revision <40자리_커밋_SHA>`를 추가해 패키지 대상 파일이 해당 커밋과 일치하는지 검사할 수 있습니다. 스크립트는 기존 ZIP과 `.sha256`을 덮어쓰지 않고, 허용 목록에 있는 런타임·소스·자산만 포함합니다. 사용자 `config.json` 대신 공개 기본 설정을 사용하고, 보관함과 로컬 인수인계 문서는 넣지 않습니다. ZIP의 `package-manifest.json`에는 포함 파일별 SHA-256이 기록됩니다.

배포 전에는 별도 폴더에 풀어 런처·프롬프트 정리·수면·우클릭·업데이트 확인과 인터넷 단절을 시험하고, 라이선스·캐릭터 사용 권한 및 배포 대상을 확인해야 합니다. 제3자 런타임 고지는 패키지 `licenses/THIRD_PARTY.md`에 담깁니다. 이 안내는 라이선스 의무의 충족이나 특정 기관의 서비스 승인을 보증하지 않습니다.
