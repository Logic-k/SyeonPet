## 같은 사례의 수정 후 재시험

문의·희망·미확정 상태를 유지하고 요청하지 않은 형식 제한을 강제하지 않도록 AI 지시문을 보완했습니다. 또한 인식 가능한 자료의 원문 보존과 사용자 추가 조건의 결과 검토를 보완한 뒤 같은 가상 사례로 다시 요청했습니다. 아래 세 JarvisClaw 응답의 종료 사유는 모두 `stop`이었습니다.

| 가상 업무 사례 | 재시험 결과 |
| --- | --- |
| 회의록 정리 | JarvisClaw 16.97초. 날짜·결정 및 미결 조건은 포함했으나 AI가 `[가상 회의록 메모 붙여 넣기]`라는 변형된 빈칸을 남겼습니다. 션은 자료 원문이 빠진 것을 감지해 결과 뒤에 그대로 붙였으므로 변형된 빈칸과 원문이 함께 보였습니다. |
| 학교 문의 회신 | JarvisClaw 15.30초. 학교가 문의한 내용을 답변 초안 작성 주체처럼 표현했고 미확인 처리 기한을 문의처 항목에 두어 의미가 달라질 가능성이 남았습니다. 날짜와 숫자가 있다는 것만으로 원문 의미가 보존된 것은 아닙니다. |

이후 지시문과 자료 빈칸 처리를 다시 보완한 뒤 같은 두 사례를 각각 한 번 더 시험했습니다. 문의 회신은 JarvisClaw가 24.70초에 `stop`으로 응답했지만, 학교를 답변 작성 주체처럼 표현하고 문의한 날짜를 확인된 일정으로 분류하는 문제는 여전히 나타났습니다. 이 응답을 저장한 뒤 최신 문자 검토 함수를 별도로 적용했을 때 원문과 대조하라는 경고가 표시됐습니다. 회의록은 31.94초에 `stop`으로 응답했고 션이 자료 원문을 빈칸에 한 번 그대로 넣어, 이 사례에서는 빈 자료칸이 남지 않았습니다. 션의 자료 원문 삽입 결과와 AI가 직접 생성한 내용을 구분해야 합니다.

이 재시험은 조건당 한 번이며 수정 후에도 의미 변화가 남았습니다. 서비스가 공유하는 모델과 부하가 달라질 수 있으므로 수정 전후 숫자만으로 정확도 개선률이나 속도 향상을 주장할 수 없습니다. 자료 복구는 인식 가능한 일부 자료와 빈칸 형식에 한정되며 모든 자료 형태를 자동으로 해결하지 못합니다. 원문에 문의·희망·예정·미확인 표현이 있고 결과에 `확인된 사실` 또는 `확정` 표현이 감지되면 상태를 대조하라는 참고 경고도 표시합니다. 이 검사는 문자 패턴 기반이므로 의미를 검증하지 않고, 실제로 문제없는 문장에도 경고할 수 있으며 모든 의미 변화를 찾아내지는 못합니다.

## 자료와 사용 조건

서비스의 모델, 한도, 약관과 가용성은 바뀔 수 있으므로 사용 시점에 다시 확인하세요. JarvisClaw는 요청을 외부 모델 공급자에게 전달할 수 있습니다. 이번 확인에서는 [개인정보 처리방침](https://api.jarvisclaw.ai/privacy-policy)의 현재 본문을 불러오지 못해 현재 보관 기간을 확인하지 못했습니다. 실제 업무자료를 사용하기 전 기관 지침과 허용 여부를 확인하세요. Pollinations의 방침은 생성 응답 캐시를 통상 최대 30일 보관할 수 있고 커뮤니티 모델 제공자별로 별도 보관 정책이 적용된다고 설명합니다. 두 서비스 모두 기관의 사용 승인을 확인하지 않았습니다. 가상 또는 공개가 허용된 자료를 사용하세요.

[Murakumo 무료 서비스 안내](https://murakumo.cloud/free)는 무료 요청이 제3자 운영 노드에서 처리되어 해당 운영자가 입력과 응답을 볼 수 있다고 설명합니다. [이용 약관](https://murakumo.cloud/legal-terms)은 초안이라고 표시하며 조직을 대신해 이용할 경우 권한이 필요하다고 명시합니다.

[OpenRouter 무료 모델 안내](https://openrouter.ai/collections/free-models)와 [개인정보 처리방침](https://openrouter.ai/privacy)은 무료 모델 제한과 제공자별 자료 처리 조건을 확인하는 출발점입니다. 앱에서 선택하는 **기본 정리 (AI 사용 안 함)**는 모델 설치나 외부 AI 전송 없이 원문을 구조화하지만, AI 재작성이나 사실 검증은 아닙니다. 별도의 앱 업데이트 확인에는 네트워크가 사용될 수 있습니다.
