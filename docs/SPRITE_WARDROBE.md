# Sprite-Gen 의상 아틀라스 가져오기

션이 옷장의 기본 의상과 소품은 앱에 미리 준비되어 있으므로 이미지 생성이나 별도 설치 없이 선택할 수 있습니다. 다음 안내는 직접 준비한 외형 팩을 가져오려는 경우에만 필요합니다. 팩 가져오기는 컴퓨터에 이미 준비한 스프라이트를 읽으며, 이미지를 자동 생성하거나 외부 서비스로 전송하지 않습니다. 이미지와 캐릭터의 사용 및 재배포 권리는 별도로 확인해야 합니다.

## 준비할 파일

Sprite-Gen 등으로 각 동작을 제작하고 검수한 뒤 아래와 같이 최종 투명 PNG와 매니페스트를 준비합니다. 두 매니페스트는 기존 `assets/manifest.json`, `assets/thinking/manifest.json`과 같은 Sprite-Gen 아틀라스 구조(`frame_layout.rows`, `animation.rows`)를 사용합니다. 예전 입력 이미지는 직접 바꾸지 마세요.

```text
의상-폴더/
  manifest.json
  sprite-sheet-alpha.png
  thinking/
    manifest.json
    sprite-sheet-alpha.png
```

기본 아틀라스에는 `idle` 8, `walk` 12, `wave` 8, `sleep` 4, `drag` 4, `celebrate` 9, `jump` 8, `dance` 10, `liesleep` 6, `still` 6프레임이 필요합니다. `thinking`에는 6프레임이 필요합니다. 각 프레임은 256×256이어야 하며 매니페스트의 프레임 좌표, 개수, 반복 여부와 재생 시간이 유효해야 합니다. 각 프레임에는 내용과 투명한 부분이 모두 있어야 합니다.

Sprite-Gen이 출력하는 중간 프레임을 무조건 적용하지 말고 정리·선택한 결과로 아틀라스를 구성하세요. 기존 고민 모션의 실제 생성과 후처리 절차는 [GitHub의 제작 기록](https://github.com/Logic-k/SyeonPet/blob/main/docs/THINKING_SPRITE.md)을 참고할 수 있습니다. 이 절차만으로 모든 자세의 새 옷이 완성되거나 캐릭터 형태가 보존된다고 보장할 수 없습니다.

## 적용과 점검

션이 옷장에서 로컬 폴더를 선택하면 각 파일의 형식과 프레임을 확인하고, 통과한 파일을 사용자 데이터 폴더에 새 팩으로 복사합니다. 원본 파일은 수정하지 않습니다. 포맷 검사는 각 포즈에서 옷 위치가 자연스러운지 판정하지 못하므로 걷기, 드래그, 잠자기, 고민과 좌우 전환을 직접 확인하세요. 이상이 있으면 기본 모습으로 되돌리고 원본 팩을 수정해 새 팩으로 가져오세요.
