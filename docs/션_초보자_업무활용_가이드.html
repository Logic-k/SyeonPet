SyeonPet v0.2.0 초보자 가이드

🌱 바탕화면 AI 비서 션(Syeon)과 함께하는 초간단 업무 활용법

복잡한 AI 프롬프트를 몰라도 괜찮아요! 클릭 몇 번으로 공문 초안·안내 문자·엑셀 수식·파일 검색까지 한 번에 끝내는 실무 가이드입니다.

✨1초 완성 초안 (문자·공문·메일)
🔍폴더 지옥 탈출 (초성·문서본문 검색)
🛡️개인정보 안심 (주민번호·전화번호 자동 가림)
🎒가방 속 할 일 (클릭 시 칭찬 세레머니)
1

1단계: 설치 및 첫 실행

션은 별도의 복잡한 설치 과정이나 관리자 비밀번호(UAC) 없이 바로 실행할 수 있습니다.

💿 원클릭 간편 설치 파일 (추천)

SyeonPet-Setup-0.2.0.exe를 더블클릭하면 5초 만에 개인 프로그램 폴더에 자동 설치되고 바탕화면에 귀여운 션 바로가기가 생성됩니다.

📦 무설치 포터블 ZIP 파일

압축을 원하는 폴더에 푼 뒤, 바탕화면에_션_바로가기_만들기.cmd를 더블클릭하면 바탕화면에 즉시 바로가기가 만들어집니다. (또는 SyeonPet.exe 직접 실행)

💡 팁: 업무용 PC 보안 정책으로 설치가 제한된 컴퓨터에서도 사용자 권한만으로 100% 안전하게 동작합니다.
2

2단계: 션과 친해지기 (조작법 & 힐링)

바탕화면 오른쪽 아래에서 살랑살랑 움직이는 션은 다양한 방법으로 당신을 돕습니다.

  • 한 번 클릭: 션 머리맡에 4가지 핵심 버튼이 담긴 '빠른 실행 알약 바'가 떠오릅니다.
  • 더블클릭: 종합 업무 비서 창(Workspace Hub)이 열립니다.
  • 머리 쓰다듬기 (마우스로 문지르기): 션을 마우스로 가볍게 여러 번 쓰다듬으면 반짝이는 하트 파티클을 띄우며 기뻐합니다 💕
  • 집중 · 휴식 타이머: 25분 집중 타이머를 켜면 션 위에 귀여운 시간 배지가 나타나 남은 시간을 알려줍니다.
  • 시간대별 케어 말풍선: 출근 시간, 점심시간, 퇴근 무렵이 되면 지친 직장인을 위한 따뜻한 한마디를 건넵니다.
3

3단계: ✨ 바로 도움받기 (초안 3초 완성)

"AI한테 뭐라고 질문해야 하지?" 고민하지 마세요. 필요한 업무를 말하듯이 편하게 적으면 션이 알아서 완성된 초안을 써 드립니다.

📱 추천 예시 칩 원클릭

상단의 [학부모 안내문자], [협조 메일], [공문 기안], [회의록 정리], [엑셀 수식] 버튼을 누르면 입력창에 표준 예시가 자동으로 채워집니다.

🛡️ 개인정보 자동 가리기

실수로 학생/학부모 이름, 주민등록번호, 휴대전화 번호가 들어가면 경고 배너가 뜨며, [🛡️ 개인정보 가리기]를 누르면 즉시 [연락처 가림] 형태로 마스킹됩니다.

🔒 보안 약속: '⚡ 즉시 서식 초안' 모드는 인터넷 연결 없이 내 컴퓨터 안에서 즉시 서식을 만듭니다. '무료 AI' 모드 사용 시에도 전송 전 확인 창이 뜨며 개인정보는 절대 전송하지 않습니다.
4

4단계: 🔍 내 파일 찾기 (폴더 지옥 탈출)

수많은 폴더 속에 파묻힌 파일, 이름이 가물가물할 때 션의 스마트 파일 탐정이 찾아드립니다.

  • 초성 검색: ㅇㅅㅇㄴ만 입력해도 '운영계획안'을 즉시 찾습니다.
  • 자연어 키워드 검색: 어제 카톡 엑셀, 지난주 다운로드 한글처럼 입력해 보세요.
  • 문서 본문 검색: 파일 이름뿐만 아니라 한글(HWP/HWPX), 워드(DOCX), 엑셀(XLSX/CSV), PDF 본문 속 단어도 찾아냅니다.
  • 스마트 버전 묶음: 최종_진짜최종_수정본.hwp 같은 중복 파일들을 최신본 1개 아래에 깔끔하게 묶어 정리해 줍니다.
  • ✨ 션에게 요약 맡기기: 찾은 파일 카드의 버튼을 누르면, 문서 본문을 션 비서 창으로 가져와 3줄 요약과 할 일 목록을 즉시 만들어 줍니다.
🛡️ 100% 오프라인 안전 검색: 파일 인덱싱과 내용 검색은 오직 사용자의 로컬 컴퓨터 내에서만 수행되며, 외부 서버로 일절 전송되지 않습니다. .exe, .bat 등 위험한 실행 파일은 실행 버튼이 자동 차단되어 안전합니다.

5단계: 🎒 가방 속 할 일 & 자주 묻는 질문 (FAQ)

🎒 할 일 · 메모

오늘 처리해야 할 일을 가볍게 메모하세요. 체크박스를 눌러 완료하면 션이 신나게 만세를 부르며 칭찬해 줍니다!

🔍 글자 크기 조절

비서 창 오른쪽 위의 '글자 크기' 드롭다운에서 보통, 크게, 아주 크게를 선택하면 모든 텍스트가 시원하게 커집니다.

자주 묻는 질문 (FAQ)

  • Q. 마우스 클릭이 션을 뚫고 지나가요 (클릭 통과 모드):
    실수로 클릭 통과 모드가 켜진 경우, 단축키 Ctrl + Alt + S 를 누르거나 작업표시줄 트레이 아이콘을 우클릭하여 해제할 수 있습니다.
  • Q. 컴퓨터를 켤 때 션이 자동으로 시작되게 하려면?
    션 우클릭 → ⚙️ 화면 · 설정 · 바로가기 → [✓] Windows 시작 시 자동 실행을 체크하세요.
  • Q. 션의 움직임을 멈추고 조용히 일하고 싶어요:
    션 우클릭 → ⚙️ 화면 · 설정 · 바로가기 → 고요 모드를 켜면 애니메이션이 멈추고 배경에서 얌전히 대기합니다.
