# 션 프롬프트 도우미 기능·디자인 조사

조사일: 2026-10-31. 기존 프로젝트의 범위에 따라 부산광역시 서부교육지원청을 대상으로 공개자료를 살펴보았다. 이 문서의 제안은 공개자료와 현재 앱을 바탕으로 한 가설이며, 직원 인터뷰나 사용성 조사 결과가 아니다. 기관의 도입·감수 또는 특정 AI 서비스의 사용 승인을 의미하지 않는다.

## 업무 맥락과 개선 방향

[서부교육지원청 사전정보공표 목록](https://home.pen.go.kr/seobu/ad/bs/beffatinfosport/view/selectBeffatinfoList.do?mi=9854)은 교육 및 행정 등 여러 분야의 공개자료 접근 경로를 제공한다. 현재 앱에는 공문, 회의, 학교 지원, 안내, 행정, 시설 등의 예시가 이미 있으므로, 새 예시의 양을 늘리기보다 **필요한 예시를 빠르게 찾고 내용을 채운 뒤 결과를 확인·복사하는 흐름**을 우선 개선한다. 예시는 공식 서식이 아니며, 사실·기한·법령·담당 부서는 제공된 근거와 최신 지침을 담당자가 확인해야 한다.

1. 입력, 정리 방식, 결과와 복사를 알아보기 쉽게 배치하고 자주 쓰는 기능을 짧은 경로로 연결한다.
2. 업무별 빈칸과 원문을 확인할 수 있게 하되, 자동 검사가 사실 확인이나 개인정보 제거를 보장한다고 표현하지 않는다.
3. 요청 실패 시 입력과 결과를 보존하고, 사용자가 원인을 이해하고 다시 시도할 수 있도록 안내한다.
4. 실제 적용 전 원문·날짜·수치와 미확인 항목을 사람이 검토하도록 돕는다. [영국 정부의 프롬프트 작성 안내](https://www.gov.uk/government/publications/ai-insights/ai-insights-prompt-engineering-html)도 제공 자료에 근거한 요청과 결과 확인의 필요성을 설명한다.

## 클라우드 무료 AI와 자료 처리

사무용 PC 성능을 고려해 모델을 PC에 설치해 실행하는 방식은 이번 개선의 권장 대상에서 제외한다. 아래 서비스의 연결 코드는 현재 개발본에 존재하지만, 이 조사에서 모든 제공자의 실제 계정·생성 품질·가용성을 새로 시험한 것은 아니다. 무료 할당량, 모델, 서비스 조건은 변경될 수 있다.

| 선택지 | 확인한 점 | 적용 판단 |
| --- | --- | --- |
| Vireonix | 현재 앱의 키 없는 선택지다. [서비스 약관](https://vireonix.ai/terms)은 무료 접근과 IP별 사용량 제한을 안내하며, 입력·출력과 대화 기록이 저장 및 모델 학습·개선에 사용될 수 있다고 명시한다. | 가상 또는 공개 가능한 자료에 한해 선택할 수 있다. 기관 승인이나 무제한·항상 정상 작동을 뜻하지 않는다. |
| Pollinations Classic | 현재 앱에 선택지와 제한 오류 처리가 있다. [공식 FAQ](https://github.com/pollinations/pollinations/blob/main/enter.pollinations.ai/POLLEN_FAQ.md)는 현재 API의 크레딧과 모델별 사용 비용을 설명한다. 이것만으로 기존 Classic 엔드포인트의 현재 무료 제공·데이터 처리 조건을 확인할 수 없다. | 서비스와 기존 엔드포인트의 현행 조건 및 실제 연결을 별도로 확인하기 전까지 무료 이용을 보장하지 않는다. |
| Gemini API | 개발본에 프로필 연결 코드가 있다. [Google 요금 안내](https://ai.google.dev/gemini-api/docs/pricing)에는 모델별 무료 제공 범위가 있고 [이용 제한](https://ai.google.dev/gemini-api/docs/rate-limits)은 모델·프로젝트에 따라 달라진다. [추가 약관](https://ai.google.dev/gemini-api/terms)은 무료 서비스의 입력과 응답이 제품 개선에 사용되고 사람의 검토를 받을 수 있다고 설명하며 민감·기밀·개인정보를 보내지 말라고 한다. | 가상 예시 또는 공개 가능한 자료의 선택형 시험 후보다. 개인 API 키와 모델별 무료 제공 여부를 확인한다. |
| Groq·OpenRouter | 개발본에 프로필 연결 코드가 있다. [Groq 제한](https://console.groq.com/docs/rate-limits)은 모델과 플랜별로 다르고, [Groq 약관](https://console.groq.com/docs/legal/services-agreement)은 명시적 허가 없는 입력·출력의 모델 학습을 금지하되 서비스 제공·법적 의무 등에 필요한 처리는 허용한다. [OpenRouter 무료 모델 안내](https://openrouter.ai/collections/free-models/)에는 무료 모델의 호출 제한이 있으며, [개인정보 처리방침](https://openrouter.ai/privacy/)은 실제 모델 제공자별 보관·학습 조건이 다를 수 있다고 설명한다. | 개인 키와 모델 선택이 필요하다. 무료 모델·제한 및 해당 제공자의 처리 조건을 확인해야 하며, 실제 계정 연결 성공은 별도 검증 대상이다. |
| 앱의 기본 정리 | 외부 AI 없이 입력을 구조화하는 기존 기능이다. AI의 재작성이나 사실 검증은 아니다. | 서비스 장애 또는 외부 전송을 원하지 않을 때 사용할 수 있다. 앱의 별도 업데이트 확인은 네트워크를 사용할 수 있다. |

기존 외부 AI 서비스의 사용 가능 여부, 약관과 실제 품질은 바뀔 수 있다. 무료라는 이유만으로 업무자료를 전송하지 않으며, 전송 대상과 내용을 확인하고 소속 기관의 지침과 승인 여부를 확인한다. 이름을 바꾸는 것만으로 재식별 위험이 모두 없어지지는 않는다. [개인정보보호위원회 생성형 AI 이용 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS212&mCode=C040030000&nttId=12257)도 입력 정보와 서비스의 처리 방식을 확인하도록 안내한다.

## 화면 설계와 검증

[영국 내무부 접근성 안내](https://design.homeoffice.gov.uk/accessibility/standard/understandable)는 입력 시 사라지는 예시 문구만을 레이블로 사용하지 않고, 오류를 색상에만 의존하지 않으며 수정 방법을 알려주도록 제안한다. [GOV.UK 오류 안내](https://design-system.service.gov.uk/components/error-message/)는 입력 오류를 표시할 때 작성한 내용을 유지하도록 권한다. 이 원칙을 Qt 화면에 맞춰 적용하고, 실제 키보드 조작·화면 읽기 도구·Windows 배율 및 좁은 화면에서 별도로 확인해야 한다.

향후 현장 검증에서는 가상 자료를 사용해 예시 찾기, 빈칸 채우기, 결과 확인·복사와 실패 후 복구가 가능한지 관찰한다. 공개자료 기반의 제안만으로 실제 사용 빈도나 업무시간 단축 효과를 단정하지 않는다.
